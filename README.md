# argus — Panopto 視聴集計

Panopto の統計レポート（CSV / xlsx）を読み込み、受講者別・動画別・日別に集計して Excel に書き出すブラウザアプリ。

- 公開先: https://dfukagaw28.github.io/argus/
- **ファイルはブラウザ内だけで処理**し、外部へは送信しない（CSP で `connect-src 'none'`）。
- 元になった単一 HTML 版は `_docs/` にある。

## 機能

- 列名の自動判別（日本語・英語）。手で直した列の対応はブラウザに保存され、同じ列構成のファイルに次回から自動で使われる
- 複数ファイルの読み込み。期間が重なったレポートの同じ記録は二重に数えない
- **受講者名簿**（学籍番号・氏名・メールなど、視聴の列がない表）を読み込むと、一度も視聴していない人も集計に含める。照合はユーザー ID またはメール
- 期間・フォルダーでの絞り込み
- 動画別・受講者別・受講者×動画・**未視聴**（受講者ごと／動画ごと、完了率のしきい値を指定可）
- 印刷用レイアウト、Excel 書き出し（未視聴シートを含む）
- 読み込み・集計・Excel 作成は **Web Worker** で行うので、大きなファイル（30 万行程度）でも画面が固まらない
- **PWA**: 一度開けばオフラインでも動く。インストールすると CSV / xlsx を OS の「プログラムから開く」で直接開ける（Chrome / Edge）。新しい版は利用者が「更新する」を押したときに切り替わる

## 開発

```sh
npm ci
npm run dev      # 開発サーバー
npm test         # Vitest
npm run build    # dist/ に出力（CSP はビルド時のみ付与）
```

`main` に push すると GitHub Actions がテスト・ビルドして Pages にデプロイする。

## 構成

| パス | 役割 |
| --- | --- |
| `src/schema/` | 列名の辞書と自動判別、名簿かどうかの判定 |
| `src/parse/` | 数値・時間・日時の読み取り |
| `src/io/` | CSV / xlsx 読み込み、Excel 書き出し（ExcelJS は遅延読み込み）、列の対応の保存 |
| `src/model/` | 正規化・ファイルの統合と重複除去・集計・未視聴（DOM 非依存、テスト対象） |
| `src/engine/` | 読み込んだファイルを保持し重い処理を行うエンジンと、その Worker / クライアント |
| `src/ui/` | グラフ・表・ファイル一覧の描画 |
| `src/pwa.ts`, `pwa/sw.js`, `public/` | Service Worker（ビルド時にファイル一覧を埋め込んで `dist/sw.js` を生成）、マニフェスト、アイコン |
| `tests/` | 単体テスト |

**注意:** リポジトリは private でも、Pages のサイトは公開される。実データ（受講者情報を含む CSV など）はコミットしないこと。
